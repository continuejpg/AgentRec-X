P7-B Soft-State source changes (curated; key additions only)
================================================================

The first CPU check found two separate state-write paths:
  1. M5 extraction in _execute_plan used payload.message (the Planner query);
  2. the Agent graph's M9 persistence stage used state["user_message"], also the
     Planner query, so a rewritten query could still write long-term preferences.
Both are closed below.  The Planner query remains free and is still used for retrieval.

+        planner_retrieval: bool = False,
+        apply_user_state: bool = True,
+        state_message: str | None = None,

+        if planner_retrieval:

             role_target_changed = self._update_role_target(task_key, payload.message)
             self._mirror_role_target_to_user_key(task_key, payload.user_key)

   Planner RETRIEVE; later RETRIEVE/RERANK steps get an empty extraction:
