5. INTERPRETATION — what M3 does and does not establish
----------------------------------------------------------------------------------------------------

  M3 compares THE EXISTING FROZEN REAL AGENT SYSTEM against the preregistered fixed-fusion
  baseline. That is the claim it supports.

  M3 must NOT be interpreted as:
  - a clean test of adaptive source selection versus fusion — SELECT_SOURCE is structurally
    unreachable, so that comparison was never run;
  - a measurement of routing quality;
  - grounds for attributing the difference to routing or selection behaviour alone.

  The arms have a documented source/action-space asymmetry: fixed_fusion fuses popularity +
  sequential + metadata in one RRF ranking, while the Agent can reach a single source at a time
  and cannot express fusion at all, and cannot name popularity at all. The measured difference
  is attributable to the whole system difference — a bounded model-driven agent with its own
  prompt, actions, reasoning and completion rules versus a deterministic three-source rank
  fusion. M3 cannot separate routing from retrieval, prompting, reasoning or completion effects,
  and it does not claim to.

  The Agent was NOT modified in response to this result, and no second execution was run.
